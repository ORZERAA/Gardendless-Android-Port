# Gardendless 0.16.26 — 非官方个人适配测试版 Alpha 4

## 一、这是什么
本版本基于 [Cateners/gardendless-android](https://github.com/Cateners/gardendless-android) 工程，由使用者在 AI 编程助手协助下适配和测试，**不是游戏原作者或上游项目发布的官方版本**。

**主要修改：**
* 接入 0.16.26 游戏版本
* 本地模组包兼容

## 二、运行要求
* 最低 Android 8.1（API 27），需要系统 Android System WebView 正常可用。
* APK 约 1.21 GB，首次启动还需解压约 1.39 GB 游戏资源。建议至少预留 5 GB 空间，部分安装器可能需要更多。
* 本版使用调试签名，为测试版本，可能存在兼容性和性能问题。

## 三、安装与更新
1. 仅安装自己信任来源提供的 APK，必要时允许对应文件管理器“安装未知应用”。
2. 包名为 `com.fct.gardendless.offlinealpha`，可与上游旧版并存。
3. 已安装本系列 Alpha 1～3 的用户，可用同签名 Alpha 4 直接覆盖。**不要先卸载，不要清除数据。**
4. 首次启动或覆盖更新后可能重新解压，请保持应用前台并耐心等待。
5. 如果提示签名冲突或无法安装，不要直接卸载已有游戏；先导出存档，再排查安装包来源、签名、系统版本及剩余空间。

## 四、存档保护
* 原上游版本的进度不会自动迁入本版。请在旧版导出存档并另存备份，再尝试导入。
* 本版覆盖更新通常保留数据，但重要进度仍须先备份。卸载应用或清除数据可能丢失进度。
* 本安装包不包含制作者的手机存档或账号。不能依靠本版进行云恢复，云存档和账号相关功能未实现。

## 五、操作提示
* 单指点击/拖动用于鼠标左键操作；双指轻点用于右键，双指滑动模拟滚轮。
* 网页弹窗可点右上角关闭，或按安卓返回键优先关闭。
* 不同手机可能存在触控、滚动或 WebView 兼容问题。

## 六、测试状态与限制
* 已完成编译、APK 签名和 ZIP 对齐检查，26 项代码自动测试通过。
* 有用户实机反馈关卡可运行、弹窗修复有效；这不代表全部机型、关卡、模组和长期存档均已验证。
* 单个模组快照暂限 64 MiB、8,192 个文件；大模组可能不受支持。
